# mdnest: Gemini CLI

The instructions for this repo are in [AGENTS.md](AGENTS.md), shared by every
agent. `.gemini/settings.json` makes Gemini CLI load `AGENTS.md` (and the
`AGENTS.md` in each folder) as its context file, so nothing is repeated here.

Skills are in `.agents/skills/<name>/SKILL.md`. When a task matches one (see the
table in `AGENTS.md`), open that file and follow it.
